BurushaskiRAG

Ask the Burushaski Digital Archive in plain English. Every answer is retrieved from the archive itself - and if the archive does not contain it, the model refuses instead of guessing.

Loading the index...

How it works: one small engine - heading-aware chunking, hybrid BM25 + TF-IDF retrieval, extractive answers with the source named on every result, and an out-of-vocabulary refusal guard. The same engine runs in Python (rag_engine.py) and in your browser (app.js); rankings match. Corpus: 62 dictionary entries (Srinagar + Gilgit dialects, IPA, examples), 4 recordings, archive README and the Srinagar Burushaski research report - 94 chunks.

Measured on a labelled test set (Python build): Hit@1 1.00, Hit@3 1.00, off-topic questions refused. Small test set - a smoke test, not a benchmark. Built by Aazim Ameen with the Burushaski Digital Archive: source archive.
