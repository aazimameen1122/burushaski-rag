# BurushaskiRAG

Ask the [Burushaski Digital Archive](https://github.com/aazimameen1-dotcom/Burushaski-Digital-Archive) in plain English — word meanings in the Srinagar and Gilgit dialects, the recordings, the community's history. If the answer is not in the archive, it says so instead of guessing.

**Live: https://aazimameen1122.github.io/burushaski-rag/**

## Run it locally

```bash
python3 ask.py "What is the Burushaski word for house?"
```

No installs, no API keys — Python standard library only. The same code runs in the browser on the live site.
